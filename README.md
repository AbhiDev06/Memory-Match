# 🧠 Memory Match Game

A fun and interactive Memory Match game built using **HTML, CSS, and JavaScript**. Flip cards, find matching emoji pairs, and challenge yourself to finish with fewer moves and less time.

## 🎮 Features

- 🃏 Flip cards to find matching pairs.
- 🎯 Three difficulty levels: Easy, Medium, and Hard.
- 🔢 Track the number of moves.
- ⏱️ Track the time taken to complete the game.
- 🏆 Save your best score for each difficulty level using browser local storage.
- 🔄 Restart the game whenever you want.
- 📱 Responsive design with animated card flips.

## 🛠️ Technologies Used

- **HTML5** — Game structure.
- **CSS3** — Styling, layout, and animations.
- **JavaScript** — Game logic, card matching, timer, and score tracking.
- **Local Storage** — Saves best scores in the browser.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `memory.html` in your browser, or use the VS Code Live Server extension.
4. Select a difficulty level and start matching cards!
